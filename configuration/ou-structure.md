# Organizational Unit Structure
## OU Design
-  Created separate OUs for users, computers, and administrators
-  Designed structure to simplify Group Policy management
-  Used least privilege principles for administrative delegation
## User Organizational Units
-  HR Users
-  IT Users
-  Finance Users
-  Disabled Users
## Computer Organizational Units
-  Workstations
-  Servers
-  Test Machines

## Administrative Groups
-  Domain Admins
-  Help Desk
-  Server Administrators
## Delegation Strategy
-  Limited administrative permissions to IT OU
-  Prevented standard users from modifying GPOs
